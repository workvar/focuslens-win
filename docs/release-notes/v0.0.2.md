# FocusLens v0.0.2: Dark mode and dashboard fixes

A fixes-only release that makes dark mode work across the whole window and keeps the dashboard current without manual reloads.

## Highlights

- **Dark mode now covers the whole app.** Switching to dark mode, or following the Windows setting, used to darken only the title bar. The window, cards, sidebar, and charts now switch with it, and the dashboard numbers and labels are readable again.
- **Refresh button on the dashboard.** A clear Refresh button sits in the dashboard header, with an "Updated" time under the date so you can see how fresh the numbers are.
- **Live dashboard.** While you are viewing today, the dashboard reloads by itself every 15 seconds, so new activity shows up without a manual reload.
- **Buttons look like buttons.** Buttons use a softer square corner instead of a full pill, so icon buttons such as previous day, next day, and refresh no longer look like blobs.

## Also in this release

- Icon-only buttons (menu, delete chat, previous day, next day, refresh) show their icons instead of empty boxes.
- The window no longer flashes white behind dark mode when it is resized or first shown.

## Known issues

- Automatic refresh applies to today only. Past days load when you open them and when you press Refresh.

## Requirements

- Windows 10 version 2004 (build 19041) or later, 64-bit

## Upgrading

Existing installs update automatically in the background and apply the update on restart.
