# FocusLens v0.0.4: UI fixes and enhancements

A polish build focused on readability, control, and setup. Buttons and fields are easier to read, meeting recording is fully in your hands, nothing is deleted without asking, and FocusLens can help you install the local tools it works best with.

## Highlights

- **Readable controls.** Buttons, text boxes, and dropdowns now use the forest palette with proper contrast in both light and dark themes. Form outlines are stronger, and keyboard focus shows a clear ring.
- **Searchable model dropdown.** The Ollama model picker lists the models installed on your PC and filters as you type. You can still enter a model name that is not installed yet.
- **Meeting recording controls.** The Meetings page has a recorder with Record, Pause, Resume, and Stop. When FocusLens detects a call it asks whether to record it, with Record this meeting or Not now.
- **Permissions page.** A new Permissions tab in Settings shows what FocusLens needs (microphone, speech recognition, screen text recognition, notifications, the background agent, and start with Windows), whether each is granted, and a button to fix the ones that are not.
- **Confirm before deleting.** Deleting a chat, a meeting, or a saved recording now asks first.
- **Guided setup for Ollama and Chroma DB.** If either is missing, FocusLens asks once whether you want help. A new Local tools tab can download and install Ollama, download a model, and set up Chroma DB in a private Python environment. Nothing is downloaded until you confirm, and anything you already have installed is left alone.

## Also in this release

- Icon-only buttons now have accessible names for screen readers, and status is shown with text as well as color.
- Dialogs follow the light or dark theme, including the title bar.
- The status list points to Settings > Local tools when Ollama, a model, or Chroma DB is missing.

## Known issues

- This is a test build. The same changes are described in [v1.1.0](v1.1.0.md), which is the planned Phase 2 release.
- Windows only lets you change privacy switches yourself, so the Permissions page opens the right Settings page rather than turning them on for you.
- Setting up Chroma DB installs Python 3.12 through winget when no Python is found. If winget is unavailable, install Python from python.org and run setup again.
- Chroma DB is set up and detected in this build. Semantic memory in chat arrives in a later release.

## Requirements

- Windows 10 version 2004 (build 19041) or later, 64-bit
- Optional: [Ollama](https://ollama.com) for fully local AI. FocusLens can install it for you.

## Upgrading

Existing installs update automatically in the background and apply the update on restart.
