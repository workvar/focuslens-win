# FocusLens v0.0.1: Auto-update test build

The first tagged build of FocusLens for Windows. It exists to prove the release pipeline and the in-app updater end to end, and it carries everything built for Phase 1.

## Highlights

- **Automatic updates.** FocusLens checks GitHub Releases in the background and announces new versions with a tray notification. The Updates tab in Settings shows the release notes, downloads only after you agree, and applies the update when you restart.
- **Local AI with Ollama.** Chat with your activity data using models on your own PC, without anything leaving your machine. Claude and OpenAI remain available.
- **Screen context.** The text of your active window is read with the built-in Windows OCR engine so answers reflect what you were working on. Images are not kept.
- **Audio and meeting recording.** Meetings are detected, audio is captured, and transcription runs offline. You get a summary with action items after the call.

## Also in this release

- Streaming AI chat with conversation history and markdown rendering.
- Google sign-in through Supabase.
- A refreshed forest theme with light and dark themes.
- A tag-driven release pipeline that builds the installer and update feed.

## Known issues

- This is a test build. Expect rough edges and use v1.0.0 or later for everyday work.
- Offline transcription uses the Windows desktop speech recognizer, which is less accurate than Whisper, and it needs a speech recognizer for your language to be installed.
- Screen context OCR depends on the OCR languages installed for your Windows user profile.
- Dark mode only darkens the title bar in this build. This is fixed in [v0.0.3](v0.0.3.md).

## Requirements

- Windows 10 version 2004 (build 19041) or later, 64-bit

## Upgrading

This is the first tagged build, so there is nothing older to update from. Download `FocusLens-win-Setup.exe` from the assets below and run it. Later builds update automatically in the background and apply on restart.
